# Meeting AI Assistant - 智能会议助手

基于 React + TypeScript + Tailwind CSS 构建的 AI 会议全流程管理工具，覆盖**会前筹备**和**会后纪要**两大核心模块。

### 功能详解

#### 1. 语料池（MaterialPool）

| 功能 | 说明 |
|------|------|
| 文本输入 | 粘贴会议相关文档、邮件、聊天记录 |
| 文件上传 | 支持 txt、md、csv、json、pdf、docx 等格式，拖拽或点击上传 |
| AI 自动摘要 | 上传/添加素材后，AI 自动分析生成摘要 |
| 相关度标记 | AI 自动评估素材与会议的相关度（高/中/低） |
| 拖拽排序 | 原生 HTML5 拖拽，调整素材优先级顺序 |
| 启用/禁用 | 单个素材可开关，禁用的素材不参与 AI 分析 |

#### 2. 智能表单（SmartForm）

| 功能 | 说明 |
|------|------|
| 会议主题 | 手动输入或 AI 从语料中提取 |
| 会议时间 | 时间选择器 |
| 会议场景 | 需求评审 / 故障复盘 / 常规同步 / 技术评审 / 其他 |
| 参会人 | 标签式输入，Enter 添加，× 删除 |
| 议程列表 | 手动添加/删除议程项（主题 + 时长 + 负责人） |
| AI 智能解析 | 点击按钮，AI 从语料池自动填充表单所有字段 |

#### 3. AI 生成议程

点击「✨ AI 生成完整议程」后，AI 综合语料池内容，一次性生成：

- **完整议程**：结构化的议题列表（主题 + 时长 + 负责人）
- **预览摘要**：会议背景与目标的一句话概要
- **会前建议**：需要提前准备的事项（含优先级和负责人分配）

#### 4. 议程时间线（EditableTimeline）

- 可视化时间轴，显示每项议程的开始/结束时间
- **拖拽排序**：原生 HTML5 拖拽调整议程顺序
- **行内编辑**：直接修改主题、时长、负责人
- 自动计算总时长

#### 5. 议程健康度（AgendaHealthBanner）

当议程超过 4 项时，自动显示警告：建议延长会议时长或拆分为两次会议。

#### 6. 会前建议（PreTodoCard）

AI 自动生成的会前待办事项列表，每条包含：
- 事项内容
- 优先级（高/中/低，带颜色标识）
- 负责人

### 功能详解

#### 1. 速记编辑区

会议结束后自动生成速记文本（transcript），用户可直接在线编辑：
- 预填充会议速记内容
- 实时字数统计
- 支持多行文本编辑

#### 2. 素材引用区

从会前上传的语料池中选择素材作为 AI 生成纪要的上下文：
- **复用会前素材**：直接展示 `meeting.materials` 列表
- **可勾选引用**：每个素材为独立卡片，带 checkbox
- **相关度标记**：高相关（红）/ 中相关（黄）/ 低相关（灰）
- **默认全选**：enabled 的素材默认勾选
- **补充材料**：可展开的额外 textarea，输入额外文本

#### 3. AI 智能提炼

点击按钮后，AI 将以下内容组合输入：

```
速记文本 + 选中素材内容 + 补充材料
         │
         ▼
   ┌──────────┐
   │ AI 分析   │
   └────┬─────┘
        │
   ┌────┴─────┐
   │          │
   ▼          ▼
结构化纪要   待办事项
(章节+决策)  (内容+负责人+截止日期)
```

#### 4. 智能章节（SmartChapters）

纪要按议题自动分为多个章节，每个章节包含：
- **时间戳**：该议题在会议中的时间点
- **标题**：议题名称
- **摘要**：AI 提炼的议题要点
- **原始片段**：手风琴展开查看该章节对应的原始速记片段
- **完整速记**：「📄 查看完整速记」按钮，打开侧边抽屉显示完整 rawInput

#### 5. 全链路文本溯源

从纪要到原始对话的完整追溯链：

```
纪要章节摘要
    │
    ├─→ 手风琴展开 → 原始速记片段（rawSnippet）
    │
    └─→ 查看完整速记 → 侧边抽屉（RawInputDrawer）
                         • CSS translate-x 动画
                         • 完整速记内容
                         • 字数统计
```

#### 6. 决策台账（DecisionLedger）

记录会议中达成的所有决策：

| 功能 | 说明 |
|------|------|
| 通过/否决 | ✓ 绿色标记通过决策，✗ 红色标记否决决策 |
| 行内编辑 | hover 显示编辑按钮，直接修改结论和理由 |
| 删除决策 | hover 显示删除按钮 |
| 标记否决 | 编辑时可勾选「标记为已否决」，显示删除线 |
| 补充遗漏决策 | 底部虚线按钮，点击新增空决策并进入编辑模式 |

#### 7. 待办看板（KanbanBoard）

基于 @dnd-kit 的三列可拖拽看板：

```
┌─────────────┬─────────────┬─────────────┐
│   待处理     │   进行中     │   已完成     │
│  (pending)  │ (in_progress)│ (completed) │
├─────────────┼─────────────┼─────────────┤
│             │             │             │
│  ┌───────┐  │  ┌───────┐  │  ┌───────┐  │
│  │ 待办1  │──│→│ 待办2  │──│→│ 待办3  │  │
│  │ 负责人 │  │  │ 负责人 │  │  │ 负责人 │  │
│  │ 截止日 │  │  │ 截止日 │  │  │ 截止日 │  │
│  │ 🔍溯源 │  │  │ 🔍溯源 │  │  │ 🔍溯源 │  │
│  └───────┘  │  └───────┘  │  └───────┘  │
└─────────────┴─────────────┴─────────────┘
       ↕ 拖拽移动 ↕
```

每张卡片包含：
- 待办内容
- 负责人
- 截止日期
- **上下文溯源**：点击展开 ContextTracePanel，显示该待办的原始对话片段（时间戳 + 发言人 + 原文）

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 19.1 | UI 框架 |
| TypeScript | 5.8 | 类型安全 |
| Vite | 6.4 | 构建工具与开发服务器 |
| Tailwind CSS | 3.4 | 原子化样式系统 |

## 快速开始

```bash
# 安装依赖（使用国内镜像）
npm install --registry=https://registry.npmmirror.com

# 启动开发服务器
npx vite --port 3000 --open

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

| 会议 | 场景 | 状态 | 用途 |
|------|------|------|------|

**推荐体验路径**：
1. 点击 seed_2 → 会后纪要 tab → 编辑速记 → 勾选素材 → AI 智能提炼
2. 点击 seed_6 → 会后纪要 tab → 查看完整纪要 + 决策台账 + 待办看板
3. 点击 seed_1 → 会前筹备 tab → 上传素材 → AI 生成议程

## 数据存储

所有数据通过 `localStorage` 持久化，无需后端服务。

清除方法：浏览器开发者工具 → Application → Local Storage → 删除 `meeting_app_data` 键。
